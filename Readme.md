# Smart Meters in London AI Project

## Overview
This project analyzes the *Smart Meters in London* dataset from Kaggle to uncover energy consumption patterns and optimize energy efficiency. By leveraging advanced data preprocessing, exploratory data analysis (EDA), and predictive modeling, the project provides actionable insights into household electricity usage across London. It demonstrates expertise in handling real-world datasets and applying AI methodologies to solve energy-related challenges.

## Features
- **Data Preprocessing**: Cleaning and transforming raw data for effective analysis.
- **Exploratory Data Analysis (EDA)**: Identifying consumption trends, anomalies, and patterns.
- **Predictive Modeling**: Forecasting energy usage using machine learning techniques.
- **Optimization Insights**: Recommendations for improving energy efficiency based on data-driven findings.

---

## Dataset
The project uses the *Smart Meters in London* dataset available on Kaggle. This dataset contains detailed records of household electricity usage across London, enabling analysis of energy consumption behaviors over time.

**Source**: [Kaggle Dataset](https://www.kaggle.com/datasets/jeanmidev/smart-meters-in-london)

## Technologies Used
- **Programming Language**: Python  
- **Libraries**: Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn  
- **Machine Learning Models**: Regression models for forecasting energy consumption  
- **Visualization Tools**: Matplotlib and Seaborn for creating insightful graphs

## Key Insights

## Installation and Usage
### Prerequisites
- Python 3.x installed
- Required libraries: Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn

### Steps:
1. Clone the repository:
   ```bash
   git clone https://github.com/ToheedAsghar/Smart_Meters_In_London_AI_Project.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Smart_Meters_In_London_AI_Project
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run the Jupyter Notebook:
   ```bash
   jupyter notebook Smart_Meters_In_London[Updated].ipynb
   ```
